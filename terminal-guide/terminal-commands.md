# Terminal Guide
1. Terminal nima? — Matnli buyruqlar interfeysi.
2. Terminal nima uchun kerak? — Fayllar, dasturlar va Git bilan tez ishlash uchun.
3. pwd — Joriy joylashuv (`pwd`).
4. ls — Fayllarni ko'rish (`ls`).
5. cd — Papkaga kirish (`cd documents`).
6. cd .. — Yuqori papkaga chiqish (`cd ..`).
7. mkdir — Papka yaratish (`mkdir my-folder`).
8. touch — Fayl yaratish (`touch notes.txt`).
9. cat — Fayl mazmunini ko'rish (`cat notes.txt`).
10. clear — Terminalni tozalash (`clear`).
11. cp — Nusxa olish (`cp notes.txt notes-copy.txt`).
12. mv — Ko'chirish/nom o'zgartirish (`mv old.txt new.txt`).
13. rm — Fayl o'chirish (`rm notes-copy.txt`).
14. git init — Repo yaratish (`git init`).
15. git status — Git holati (`git status`).
