# Terminal Guide
1. Terminal nima? — Matnli buyruqlar interfeysi.
2. Terminal nima uchun kerak? — Fayllar, dasturlar va Git bilan tez ishlash uchun.
3. pwd — Joriy joylashuv (`pwd`).
4. ls — Fayllarni ko'rish (`ls`).
5. cd — Papkaga kirish (`cd documents`).
6. cd .. — Yuqori papkaga chiqish (`cd ..`).
