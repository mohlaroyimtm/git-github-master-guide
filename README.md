# Git & GitHub Master Guide

Bu loyiha Git, GitHub va Terminal komandalarini o'rganish va hujjatlashtirish uchun yaratilgan mustaqil amaliy loyiha.

## Muallif
Ism Familiya

## Loyiha bo'limlari
- **Git Guide** (`git-guide/git-commands.md`) — Git asoslari va Git komandalari
- **GitHub Guide** (`github-guide/github-commands.md`) — GitHub platformasi va remote komandalar
- **Terminal Guide** (`terminal-guide/terminal-commands.md`) — Terminal komandalari va ularning izohlari

## Maqsad
O'rgangan komandalarimni amalda qo'llash, branchlar bilan ishlashni o'rganish va barcha bilimlarni tartibli hujjatlashtirish.
